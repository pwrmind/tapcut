# ✂️ TapCut – AI UI Layer Extractor

Инструмент для интерактивного вырезания объектов из скриншотов интерфейсов с помощью **Segment Anything Model 2 (SAM 2)** и последующего восстановления фона через inpainting.

Кликните на элемент → он будет выделен и сохранён как слой с прозрачностью, а исходное изображение очистится от этого элемента (фон дорисовывается). Повторяйте, пока не извлечёте все нужные слои.

## Возможности

- 🖱️ **Выделение по одному клику** – нажмите на объект, и SAM 2 выделит его.
- 🧩 **Сохранение в PNG с альфа-каналом** – каждый выделенный объект сохраняется как отдельный слой с прозрачным фоном.
- 🎨 **Удаление фона** – вырезанный объект заменяется дорисованным фоном (inpainting), чтобы можно было продолжить извлечение других элементов с того же скриншота.
- ⚡ **Два режима inpainting**:
  - *Быстрый (OpenCV)* – на основе алгоритма Telea, работает без интернета.
  - *Качественный (LaMa)* – нейросетевая модель, дающая более естественный результат (требуется скачивание весов ~200 МБ).
- 🖥️ **Графический интерфейс** на PyQt6 с двумя вкладками: редактор (исходное изображение) и результат (вырезанный слой).

## Требования

- Python **3.10+**
- PyTorch (желательно с поддержкой CUDA для ускорения)
- SAM 2 (модель и конфигурация)
- OpenCV (`opencv-python`)
- Pillow
- PyQt6

Опционально для качественного inpainting:
- `simple_lama_inpainting` (веса загрузятся автоматически при первом запуске)

## Установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/yourusername/tapcut.git
cd tapcut
```

### 2. Установите зависимости
Рекомендуется использовать виртуальное окружение. Удобно с `uv`:
```bash
uv sync
```
Или через pip:
```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121  # если есть CUDA
pip install opencv-python pillow pyqt6 simple_lama_inpainting
```

### 3. Загрузите модель SAM 2
Создайте папку `models/sam2-hiera-tiny/` в корне проекта и поместите в неё два файла:
- `sam2_hiera_t.yaml` (конфигурация)
- `sam2_hiera_tiny.pt` (веса)

Скачать их можно из официального репозитория [facebookresearch/sam2](https://github.com/facebookresearch/sam2):
- Конфигурация: `sam2/configs/sam2/sam2_hiera_t.yaml`
- Веса: [sam2_hiera_tiny.pt](https://dl.fbaipublicfiles.com/segment_anything_2/072824/sam2_hiera_tiny.pt)

В результате структура должна быть такой:
```
tapcut/
├── models/
│   └── sam2-hiera-tiny/
│       ├── sam2_hiera_t.yaml
│       └── sam2_hiera_tiny.pt
├── main.py
└── README.md
```

## Запуск

```bash
python main.py
```
или
```bash
uv run main.py
```

## Как пользоваться

1. Нажмите **«Открыть картинку»** и выберите скриншот UI.
2. Кликните левой кнопкой мыши по объекту, который хотите вырезать.  
   *Если SAM 2 не загрузился, будет выделяться прямоугольная область.*
3. Зелёная полупрозрачная маска покажет выделенную область. При необходимости кликните ещё раз – маска обновится.
4. Выберите метод удаления фона:  
   - **Быстрый (OpenCV)** – мгновенно, но может оставлять артефакты.  
   - **Качественный (LaMa)** – требует первого скачивания модели (~200 МБ), даёт более гладкий фон.
5. Нажмите **«Extract»**.  
   - Объект вырезается и сохраняется как PNG с прозрачностью (вкладка «Вырезанный объект»).  
   - Исходное изображение обновляется: на месте объекта восстанавливается фон.
6. Повторяйте шаги 2–5, пока не извлечёте все нужные слои.
7. Для сохранения текущего вырезанного слоя нажмите **«Сохранить вырезанный объект»**.

## Пример использования

Допустим, у вас есть скриншот мобильного приложения с несколькими кнопками. Вы кликаете по первой кнопке → она выделяется, нажимаете Extract → кнопка сохранена, а на исходном изображении она «исчезла» (заменена фоном). Затем кликаете по следующей кнопке – и так далее.
